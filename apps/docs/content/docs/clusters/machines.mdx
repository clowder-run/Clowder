## Add machines to a cluster

### Prerequisites

1. A linux machine (preferably fresh)
2. Root or passwordless sudo access to it
3. SSH access

### Setup

You can add machines to a cluster by clicking on the `Add machine` button which will have you add an ssh key on the machine you want to add
