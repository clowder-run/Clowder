## Monitoring stack

The monitoring stack is made up of [GreptimeDB](https://greptime.com/product/db), which is one engine for metrics, logs and traces, and [Grafana Alloy](https://grafana.com/docs/alloy/latest/).

Uses about ~1gb memory on "larger" clusters.
