## Setup a Git source

We currently only provide first party support for Forgejo and Github.

### Forgejo

#### Prerequisites

1. A Forgejo instance (if you don't have one you can deploy with our template)

#### Instructions

1. Go to the `Git connection` page found under configuration in the sidebar
2. Click on `Add connection`
3. Fill out the `Connection name`, select Forgejo as the provider, set the Git server URL and Authorization type
4. Follow the steps from the dashboard

### Github

#### Instructions

1. Go to the `Git connection` page found under configuration in the sidebar
2. Click on `Add connection`
3. Fill out the `Connection name`, set the provider to Github, and select the Authorization type
4. Follow the remaining steps from the dashboard

### Generic Git

#### Instructions

1. Go to the `Git connection` page found under configuration in the sidebar
2. Click on `Add connection`
3. Fill out the `Connection name`, set the provider to Generic Git
4. Fill out the authorization tokens
5. Follow the remaining steps from the dashboard
