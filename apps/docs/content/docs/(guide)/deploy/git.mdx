---
title: Git repositories
icon: GitBranch
description: Deploy a compose stack from a Git repository, optionally on every push
---

A Git resource is the same as a [compose resource](/docs/deploy/compose) just that the compose spec and configs are from a [Git connection](/docs/connections/git). Every change triggers a push if `Deploy on push` is enabled. You can also edit the compose from the dashboard, it's commited when you deploy.
